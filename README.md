# ✿ 나의 미니홈피 ✿

> *"오늘도 방문해줘서 고마워요~ ♪"*

---

## ˚✧₊⁎ 소개 ⁎₊✧˚

2000년대 감성 그대로 되살린 **개인 홈페이지 프로젝트**입니다.
그 시절 감성을 웹으로 구현합니다.

---

## ˚✧₊⁎ 기술 스택 ⁎₊✧˚

```
Frontend  : HTML5 / CSS3 / JavaScript (Vanilla)
Styling   : 반짝이는 CSS 애니메이션 ✨
Font      : 도트 폰트
Theme     : 파스텔 & 레트로 컬러
```

---

## ˚✧₊⁎ 컨셉 & 디자인 ⁎₊✧˚

- **컬러**: 파스텔 핑크, 라벤더, 민트 계열
- **폰트**: 도트 폰트
- **이펙트**: 반짝이 커서, 눈 내리는 효과, 스크롤 마퀴
- **BGM**: 자동 재생되는 감성 브금 (브라우저 정책에 따라 수동 재생)
- **레이아웃**: 테이블 기반의 레트로 레이아웃

> 💡 IE 6.0 호환은 지원하지 않습니다... 그래도 최대한 레트로하게!


---
